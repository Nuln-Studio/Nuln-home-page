关于我们

零阑工坊（Nuln Studio）是一个由独立开发者组成的开源团队，以实用、精简、开放为核心理念。所有项目均遵循 GPL-3.0 协议 开源，在 Gitee 与 GitHub 上同步维护。

团队目前由三人组成，我们欢迎新开发者加入

当前维护项目

MCOpen(MCO)

开发中

简约开源的 Minecraft Java 版启动器，纯净无广告。兼容 Forge / Fabric / NeoForge，支持离线与正版登录（开发中）

CleanSlate(白板)

正式版 v1.0.3

基于 Python 的命令行 C 盘清理工具，绿色免安装。清理完成后，系统盘就像一块全新的白板。支持补丁系统，使用 yaml 配置文件

GraphVein(GV)

开发中

基于 Python 与 PySide6 的树形逻辑导图编辑器。已完成底层画布交互（平移、缩放、节点拖拽）与 GUI 框架
